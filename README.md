There is no real use for a readme here, this is my blog using GitHub pages. This blog has 2 formats, html for humans and md for LLMs. There is a tracking pixel pointing to goatcounter in the html pages, where visitor location is collected.
You can see the visits dashboard at [https://monchitos82.goatcounter.com/](https://monchitos82.goatcounter.com/).

This blog is built by hand. Every single line. Accessibility is an important consideration for this blog, even if you don't like the colors or the fonts, their primary objective is to be WCAG compliant and score above AA.

This blog is divided into Posts (long entries talking about a technical subject) and monthly entries (rants, comments, random thoughts). Entries might change over time or just be gone. I use a pipeline written in Jenkins (and leveraging Gemma4 over ollama) to validate the content structure.
Most info will eventually be moved to the archive so expect the landing page to be plain.

Thanks for your visit.
